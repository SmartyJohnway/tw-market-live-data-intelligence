# TW-Market 1.5.0 — selected, unpublished

## Summary

TW-Market provides local Taiwan Market Evidence & Research Infrastructure for
humans and AI agents. Version 1.5.0 is selected as a compatible minor release.
Published stable remains v1.0.0. These are release-note source inputs, not a
publication announcement.

## Added / changed behavior

The accepted Phase L work hardens installation/state portability, governed
evidence acquisition, source-date/unscheduled session authority, normalization
diagnostics, truthful retrieval/finalization chronology, finalization CAS and
active Security Master propagation. Release tooling now distinguishes canonical
CI from diagnostic profiles and aligns operator/browser acceptance with the
disabled legacy HTTP execution route. Current governed Mode B remains the
explicit authorization/confirmation/execute-once authority.

## Preserved public compatibility

Published Local Service V1 clients retain explicit version negotiation and a
retained V1 capability projection; current V2/V3 contracts remain authoritative
where applicable. Unified MCP still exposes exactly six governed tools over
local stdio. Preview and validation never authorize execution. No scheduler,
automatic polling, trading, order routing or realtime guarantee is introduced.

## MCP SDK / runtime policy

CPython 3.13 is canonical release/build/CI. Windows 11 x64 is release-blocking
Native Tier-1. Python 3.11 remains noncanonical developer/source compatibility;
Python 3.12 is unsupported. MCP remains exact `mcp==1.29.0`.
