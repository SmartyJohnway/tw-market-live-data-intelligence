# Current Output Artifacts

The current product centers on governed control packages and their Result/Audit/
handoff projections.

| Artifact | Role | Network behavior | Persistence / integrity |
|---|---|---|---|
| Unified Request | caller/AI intent expressed in canonical contract | none by itself | validated before planning |
| Canonical Preview / orchestration plan | bounded deterministic execution plan | none | plan ID/hash bound into authorization |
| Authorization / control package | explicit approved operation scope | none | single-use / consumption state governed |
| Operation evidence | target/capability-specific source evidence | only during approved execute-once | target-bounded governed artifact |
| Execution receipt | records execution outcome and transport/accounting | no extra call | hash/lineage bound |
| Evidence bundle | groups governed operation evidence | no extra call | hash/lineage bound |
| Unified Result V3 | canonical AI-consumable evidence result | no extra call | new materialization defaults V3 |
| Audit Package V3 | separate execution/provenance/audit view | no extra call | new materialization defaults V3 |
| AI Handoff | AI-safe transport over verified Result/Audit | no extra call | citation/lineage references preserved |
| Persistent Watchlist revisions | durable local target state | none | installation-local immutable revision chain |

Historical persisted V1/V2/V3 output packages remain readable under their
stored version. They must not be rematerialized solely to make old artifacts
look current.
